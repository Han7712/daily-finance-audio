# Duration

今天的问题是，为什么同样是一只债券，利率变化一点点，价格反应会差这么多。

Duration，也就是久期，衡量的是债券价格对利率变化的敏感程度。你可以把它理解成债券现金流的平均等待时间。等待时间越长，未来现金流越依赖折现率，所以利率一变，现值变化就更明显。

举一个小数字例子。假设一只短债很快还本付息，另一只长债要很多年后才拿回大部分现金流。当市场利率上升时，远期现金流被折现得更多，长债价格就会更敏感。

常见误区是把久期理解成到期时间。到期时间只看最后一天，duration 会看每一笔现金流出现的时间和权重。

今天的 takeaway 是，读债券研报时看到 duration，你要立刻想到利率风险暴露。明天的问题是，为什么 duration 本身还会随着利率变化而变化。
