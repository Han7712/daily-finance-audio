# Swap Spread

上一次复习问题是：如果一个组合的一日 99% VaR 是一千万，你会怎样向 PM 解释这个数字没有覆盖的尾部损失、模型假设和压力情景？一个合格回答，要先说明 VaR 只是给定持有期和置信水平下的损失分位点，不能告诉我们超过这个分位以后会亏多少。还要检查历史窗口、相关性、流动性和 stress test，因为压力期的跳跃风险常常在正常波动模型之外。

今天的问题是：为什么利率互换的固定利率，有时会高于同期限国债收益率，有时又会低于它？这个差值在研究利率、银行信用和市场结构时能告诉我们什么？

Swap Spread，中文可叫互换利差，通常指同期限 interest rate swap，也就是利率互换的固定利率，减去同期限 Treasury yield，也就是美国国债收益率。利率互换里，一方支付固定利率，另一方支付浮动利率，常见浮动端和 SOFR 相关。国债收益率代表美国政府债券的市场收益率。两者相减以后，得到的 spread 可以被理解为互换市场相对国债市场的价格差。

机制可以分四层看。第一，互换固定利率反映银行体系和衍生品市场里的资金、信用和对冲需求。交易对手虽然有抵押品和清算机制，仍然会涉及保证金、资本占用和交易商中介成本。第二，国债收益率不只反映无风险利率，也受国债供给、避险需求、回购融资和抵押品稀缺程度影响。第三，资产负债表容量会改变价差。若 dealer balance sheet capacity，也就是交易商资产负债表容量，变得紧张，做市商持有国债、提供互换报价和做相对价值交易的成本会上升。第四，方向也要分期限看。短端更受政策利率和融资影响，长端更容易受久期供给、养老金对冲和宏观避险需求影响。因此，正负号本身只是起点，真正重要的是同时解释两条曲线各自移动的原因。

第一个例子看国债供给。假设财政发行很多长期国债，市场需要吸收更多 duration，也就是久期风险。若投资者要求更高收益率才愿意买国债，十年期国债收益率可能上升得比十年期 swap rate 更快。此时 swap spread 会收窄，甚至变成负值。研究员不能只说利率上行，还要问上行来自政策预期，还是来自国债本身变便宜。

第二个例子看银行和企业对冲。一个保险公司持有长期固定收益资产，想用互换管理久期。若它大量 receive fixed，也就是收固定利率、付浮动利率，市场上对收固定的需求上升，swap fixed rate 可能被压低。相反，若企业集中 pay fixed，用互换锁定未来融资成本，固定端需求上升，swap rate 可能抬高。两种 flow 都会改变 swap spread，并且未必来自宏观利率观点。

常见误区是把 swap spread 当作单纯的银行信用指标。早期市场里，互换交易对手主要是银行，正的 swap spread 常被解读为银行信用和资金成本补偿。现在清算、抵押品、SOFR 转换、国债供给和监管资本都很重要，所以同一个 spread 变化可能有多种来源。另一个误区是认为国债永远比互换更接近无风险折现率。实际建模时，OIS discounting，也就是隔夜指数互换折现，常用于抵押化衍生品定价；国债收益率还包含抵押品和供需溢价。

实用 takeaway 是，读 rates 策略时看到 swap spread 变化，要按三个问题拆分：swap rate 为什么变，Treasury yield 为什么变，做相对价值交易的 balance sheet 成本有没有变化。这也会影响套保成本和相对价值仓位的盈亏解释。面试里可以把它说成一个连接政策预期、国债供给、银行信用、对冲 flow 和市场结构的综合信号。

明天的复习问题是：当十年期 swap spread 从正值转为负值时，你会怎样拆分国债供给、互换对冲需求、银行信用和资产负债表约束？
