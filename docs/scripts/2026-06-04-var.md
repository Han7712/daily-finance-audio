# Value at Risk

上一次复习问题是：如果同一发行人两只债券基本面相近，但成交更活跃的一只收益率更低，你会怎样拆分信用风险、供需因素和 liquidity premium？一个合格回答，要先看信用基本面是否真的一样，再看新券供给、指数纳入、做市商库存和成交深度。若违约风险接近，但买卖价差更窄、交易更连续、压力期也更容易卖出，较低收益率很可能包含了流动性优势。

今天的问题是：当风险报告说一个组合的一日 99% VaR 是一千万，这句话到底能告诉你什么，又不能告诉你什么？

Value at Risk，常缩写为 VaR，中文可叫风险价值。它衡量在给定持有期和置信水平下，组合在正常市场条件中可能遭受的最大损失阈值。比如一日 99% VaR 是一千万，意思是按照模型估计，在一百个相似交易日里，大约九十九天的损失不会超过一千万。它描述的是损失分布上的一个分位点，用来把不同组合、不同交易台和不同资产类别的市场风险放到同一张风险表里比较。

机制可以分四步理解。第一，先确定持有期，比如一天、十天或一个月。持有期越长，价格变化累积越多，VaR 通常越大。第二，确定置信水平，常见是 95% 或 99%。置信水平越高，看的损失分位越靠尾部，数字也越大。第三，选择估计方法。Variance covariance method，也就是方差协方差法，假设收益接近正态分布，用波动率和相关性计算损失。Historical simulation，中文可叫历史模拟法，直接把过去市场变化套到今天组合上。Monte Carlo simulation，中文可叫蒙特卡洛模拟，通过大量随机路径估计损失分布。第四，把每个资产的价格敏感度、相关性和非线性风险合在一起，得到组合层面的损失分布。这里最关键的判断，是模型能否把主要风险因子映射到真实头寸，例如股票 beta、利率久期、信用利差、汇率敞口和期权希腊值。

第一个例子看股票组合。一个基金持有科技股、消费股和指数期货。单只股票波动很大，但如果行业相关性较低，组合 VaR 可能小于单个头寸 VaR 的简单相加。问题在于，压力时期相关性常会上升。平时看起来分散的资产，遇到流动性收缩时可能一起下跌，所以 VaR 数字需要和相关性假设一起读。

第二个例子看债券交易台。交易台持有长期国债，同时用利率互换对冲一部分久期。若收益率每天小幅波动，VaR 会反映久期敞口和曲线变化的影响。但如果发生突发政策冲击，收益率跳升、swap spread 同时变化，历史窗口没有包含类似情景，VaR 可能低估实际损失。交易员还要检查曲线风险，因为两年、十年和三十年利率未必同步移动。因此风控会把 VaR 和 stress test，也就是压力测试，放在一起看。

常见误区是把 VaR 当成最大亏损。真正超过 VaR 的那 1% 情形，亏多少并没有被这个数字说明。另一个误区是只看 VaR 下降就认为风险降低。VaR 下降可能来自真实减仓，也可能来自近期波动率偏低、相关性估计变化，或模型没有捕捉到流动性和跳跃风险。风险经理通常会追踪 backtesting，也就是回测，观察实际超过 VaR 的次数是否和置信水平大致匹配。

实用 takeaway 是，读 VaR 时一定追问三个条件：持有期多长，置信水平是多少，模型用的历史窗口和分布假设是什么。做模型或面试时，可以说 VaR 擅长度量正常市场中的可比较风险，但需要 Expected Shortfall，也就是超过 VaR 后的平均损失，以及压力测试来补充尾部视角。

明天的复习问题是：如果一个组合的一日 99% VaR 是一千万，你会怎样向 PM 解释这个数字没有覆盖的尾部损失、模型假设和压力情景？
