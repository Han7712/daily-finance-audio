# Rating Migration

## 1. 上次复盘

上次我们问，如果一家 BB 发行人的短端信用利差快速走宽，同时评级展望被调成负面，怎样区分这是 credit curve 对再融资风险的重新定价，还是评级迁徙已经被提前交易。核心线索有三个：先看短端到期墙和现金覆盖，再看二级市场是否只惩罚近端债，最后看同业债券有没有同步走弱。

## 2. 今天的问题

今天的问题是，Rating Migration，评级迁徙，为什么会让一只债券在真正被降级前就开始重新定价？如果你在读研报或做信用模型，应该盯哪些信号。

## 3. 概念定义

Rating Migration 指发行人或债券信用评级从一个等级移动到另一个等级的过程，可以上调，也可以下调。这里的评级通常来自 rating agency，评级机构，例如标普、穆迪或惠誉。投资里更常见的关注点是 downgrade，下调评级，因为它会改变违约概率、融资成本、投资者可买范围和指数资格。比如 BBB 掉到 BB，叫 fallen angel，中文常说堕落天使债，意思是从 investment grade，投资级，落入 high yield，高收益债。

## 4. 机制拆解

评级迁徙影响价格，第一层来自预期损失。评级下移通常对应更高的违约概率，投资者要求更高的 credit spread，信用利差，来补偿风险。第二层来自强制交易。很多基金、保险账户、指数产品有评级门槛，一旦债券失去投资级资格，部分投资者必须减仓，潜在卖压会被市场提前折现。第三层来自融资反馈。评级下降后，新发债成本上升，银行授信可能变紧，企业再融资空间收缩，基本面压力又会反过来支持更宽的利差。第四层来自流动性。降级预期越集中，买方越少，交易商也会降低做市意愿，bid ask spread，买卖价差，可能明显扩大。

建模时可以把评级看成状态变量。今天的 BBB、明年的 BB、后年的 B，每个状态都有不同违约概率、回收率假设和贴现利差。你不需要预测一个单点结果，而要估计多条路径的概率加权价格。

## 5. 两个例子

第一个例子看地产或高杠杆工业公司。公司短期没有违约，但销售回款变慢，净债务对 EBITDA 上升，评级展望先被调成负面。债券价格可能已经下跌，因为市场担心下一步从 BB 加号移到 BB，或者继续落到 B 档。模型里不能只看今天的票息和到期收益率，还要给未来评级路径一个概率。

第二个例子看 BBB 边缘发行人。假设公司并购后杠杆短期上升，管理层承诺两年内去杠杆。若自由现金流兑现，评级可能稳定；若盈利下修，fallen angel 风险上升。此时同样是 BBB 债，离降级一步之遥的债通常要给更高利差，因为投资者已经在价格里加入迁徙风险。

## 6. 常见误区

常见误区是把评级当作滞后标签，只等正式公告。实际交易中，市场、评级机构和公司财务数据彼此互动。评级公告经常滞后于价格，但公告本身仍有影响，因为它会触发投资授权、指数规则和风控系统。另一个误区是只看单一评级。很多组合规则看三大评级机构的中位数或最低评级，所以要确认具体契约怎么写。

## 7. 实用结论

做研究时，可以把 rating migration 当成一条路径来建模：现在评级、展望、关键财务指标、到期墙、管理层行动和行业周期。真正有用的判断，不止是会不会降级，还包括何时降级、被谁降级、会触发哪些持有人卖出。

面试或投委会里，最有价值的回答通常会把财务触发点和市场触发点连起来：例如杠杆率超过多少会导致展望下调，指数剔除会带来多大被动卖压，现金流修复能否把迁徙路径拉回稳定区间。
