# Daily Finance Audio 2026-07-02

一、昨日复盘。上次的问题是：如果十年期收益率快速上行，同时 MBS duration 明显延长，你会怎样区分这轮 selloff 里，哪一部分来自宏观预期变化，哪一部分来自 mortgage convexity hedging？一个合格回答，要先看宏观线索，比如通胀、就业、央行预期和实际利率是否同步上修；再看按揭线索，比如再融资激励是否下降，MBS duration 是否被动延长；最后看交易线索，比如 swap pay flow、长端国债卖盘和 MBS 利差是否集中出现。三层合在一起，才能判断是基本面重定价，还是对冲流放大了波动。

二、今天的问题。为什么一只股票上涨越快，做市商有时越需要继续买入同一只股票，从而把涨势推得更急？今天讲 Gamma Squeeze，中文可理解为伽马挤压。

三、概念定义。Gamma Squeeze 出现在期权市场和股票现货之间。Option，中文是期权，给买方在未来按约定价格买入或卖出资产的权利。Call option，中文是看涨期权，价格上涨时价值上升。Delta，中文可理解为期权价格对标的价格的一阶敏感度，表示股票涨一块钱，期权大约变动多少。Gamma，中文可理解为 delta 对标的价格变化的敏感度，说明股票价格每变动一段，delta 会怎样调整。Gamma Squeeze 指大量看涨期权买盘让卖出期权的做市商需要动态买入股票来对冲 delta，股票越涨，delta 越高，对冲买盘越多，短期价格压力就可能自我强化。

四、机制拆解。第一，投资者集中买入短期限、虚值或平值看涨期权，做市商通常站在卖方。第二，做市商为了保持 delta neutral，也就是让方向性股票风险接近中性，会买入一部分股票作为 hedge，中文可叫对冲。第三，当股票继续上涨，看涨期权的 delta 上升，做市商原来的股票对冲不够，需要补买更多股票。第四，越接近到期日，gamma 往往越高，同样一小段股价变化会带来更大的 delta 调整。第五，如果标的股票流动性有限、空头拥挤或成交集中在少数行权价附近，对冲买盘就可能把价格推向下一组行权价，再触发新一轮对冲。

五、两个例子。第一个例子看个股财报。假设一家公司财报后股价从五十涨到五十八，散户和基金同时买入六十行权价的一周期 call option。做市商卖出这些期权后，随着股价接近六十，delta 快速抬升。为了减少被动空头风险，他们不断买入股票，结果股价更容易冲过六十。研究员看到这种走势，不能只写盈利预期上修，还要检查期权成交量、open interest，也就是未平仓合约，和各行权价附近的 gamma 分布。

第二个例子看指数。若一个重要指数在月度期权到期前接近关键行权价，很多短期期权的 gamma 集中在这个位置。指数小幅上行时，做市商补买期货或 ETF；指数小幅下行时，他们可能卖出对冲仓位。结果盘中波动会变得更机械，价格像被几个行权价牵引。组合经理做 intraday risk，也就是日内风险管理时，不能只看宏观新闻，也要看期权到期、dealer gamma 和现货流动性。

六、常见误区。Gamma Squeeze 不等于基本面变好，也不等于每次期权成交放大都会出现暴涨。它需要几个条件同时具备：看涨期权买盘足够集中，做市商整体处在需要追买的对冲方向，标的流动性没有完全吸收订单，并且价格接近高 gamma 区域。另一个误区是把它和 short squeeze，也就是空头回补挤压混在一起。Short squeeze 的核心是空头被迫买回股票，Gamma Squeeze 的核心是期权卖方为了控制 delta 风险而动态买入或卖出标的。

七、实用结论。读股票策略、期权报告或交易复盘时，看到某个名字短期暴涨，要问四件事：上涨是否伴随短期期权成交放大，call option 的 open interest 集中在哪些行权价，dealer gamma 是正还是负，现货成交量能否吸收对冲流。面试里可以说，Gamma Squeeze 帮你把期权仓位翻译成现货市场的机械买盘或卖盘。
