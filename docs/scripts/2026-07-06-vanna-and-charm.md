# Vanna and Charm

上一期我们留了一个问题：如果隐含波动率曲线突然左偏更陡，但指数现货还在上涨，你会怎样判断这是尾部保护需求、做市商库存压力，还是基本面风险已经提前进入期权价格？一个实用顺序是先看成交集中在哪些执行价，再看期限结构是否同步变化，最后看现货、波动率和做市商对冲方向是否彼此印证。

今天的问题是：为什么同样是期权仓位，有时现货小幅上涨会触发交易台继续买入标的，有时又会触发卖出？答案常常藏在两个二阶希腊值里，Vanna 和 Charm。

Vanna 指期权 Delta 对隐含波动率变化的敏感度，也可以理解为 Vega 对现货价格变化的敏感度。Delta 是期权价格对标的价格的第一层反应，Vega 是期权价格对隐含波动率的反应。Vanna 把这两条线连起来，告诉我们当波动率上升或下降时，对冲 Delta 的数量会怎样改变。

Charm 指 Delta 随时间流逝而变化的速度，也叫 Delta decay。它关注时间本身带来的对冲需求：即使现货不动、波动率不动，临近到期的期权 Delta 也会自然漂移。越接近到期、执行价越接近平值，这种时间推动的 Delta 变化越需要被管理。对交易台来说，这相当于仓位每天自动换了一点形状，昨天中性的组合，今天开盘可能已经带有新的方向暴露。

机制可以分三步看。第一，做市商卖出期权后，会用标的或期货做 Delta hedge，也就是用现货头寸抵消价格方向风险。第二，当市场隐含波动率变化时，Vanna 会改变这些期权的 Delta。如果波动率下降让某一批看涨期权 Delta 上升，做市商可能需要买入更多标的补对冲。第三，时间每天流逝，Charm 会让短期期权的 Delta 自动靠近零或靠近一，具体方向取决于期权是价内、价外还是接近平值。于是，即使新闻不多，收盘前或到期日前后也可能出现机械性买卖。

第一个例子看指数反弹。假设大量投资者买入短期限看涨期权，做市商处在卖出看涨的一边。若指数缓慢上涨，同时隐含波动率回落，Vanna 可能让这些看涨期权的 Delta 继续上升。做市商为了维持中性，需要买入指数期货。这个买入会反过来推高现货，形成看起来很顺的上涨动量。研究员读盘时，如果只看基本面消息，会低估期权对冲流对价格的放大作用。

第二个例子看财报前的个股期权。财报公布前，短期期权隐含波动率很高，财报后波动率通常快速回落。如果市场之前堆了很多看跌保护，波动率塌缩会通过 Vanna 改变看跌期权 Delta，做市商可能需要减少空头对冲。与此同时，期权离到期更近，Charm 让部分价外保护的 Delta 快速衰减。这两股力量叠加，可能让股价在坏消息不大的情况下出现短暂反弹。

常见误区是把 Vanna 和 Charm 当成预测工具。它们更适合用来解释仓位如何被迫调整，单独拿来判断方向会很危险。方向还取决于谁持有期权、做市商是净多还是净空 Gamma、成交集中在什么期限和执行价，以及现货是否已经接近关键行权区。如果这些背景没有确认，只看到一个希腊值变大，就容易把被动对冲流误读成主动观点。

实践上，看到临近到期的集中期权仓位时，可以问三件事：波动率如果下降，Delta hedge 会增加还是减少？时间流逝会让哪一侧 Delta 更快消失？这些对冲流和基本面资金是同向还是反向？把这三点连起来，Vanna 和 Charm 就会从抽象希腊值变成读懂盘面微观结构的工具。
