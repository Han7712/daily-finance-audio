# Repo Market Mechanics

上一次复习问题是：当两年期 SOFR OIS 明显下移，但同期限国债收益率几乎不变时，你会怎样拆分政策利率预期、期限溢价、国债供需和抵押品因素？一个合格回答，要先看短端 OIS 是否在重定价降息路径，再看国债收益率里有没有财政供给、期限溢价或避险买盘的抵消。若 OIS 下行而国债不动，说明衍生品市场的政策预期已经变化，但现金国债市场还被供需和抵押品因素拉住。

今天的问题是：为什么回购市场经常被称为金融体系的短期资金管道？当 repo rate 突然上行时，它是在告诉我们现金紧张，抵押品紧张，还是 dealer 的资产负债表紧张？

Repo Market Mechanics，中文可理解为回购市场运行机制。Repo 是 repurchase agreement，也就是回购协议。一方把证券卖给另一方，同时约定未来按更高价格买回。经济含义上，这通常是一笔有抵押的短期借款：借钱的一方交出国债等 collateral，也就是抵押品；出钱的一方收取利息，这个利息就体现在 repo rate，中文可叫回购利率。

机制可以分四层看。第一，repo 把现金和高质量证券连接起来。持有国债但缺现金的机构，可以用国债换来隔夜或短期资金；持有现金的货币市场基金，可以通过 repo 获得抵押品保护和利息收入。第二，haircut，也就是折扣率，决定同一批抵押品能借出多少现金。抵押品越安全、越容易卖，haircut 通常越低；抵押品越复杂或流动性越差，haircut 越高。第三，repo rate 受到现金供给、抵押品供给和交易对手资产负债表共同影响。现金稀缺会推高利率，热门抵押品稀缺时反而可能出现 special repo rate，也就是特定券低于一般融资利率的特殊回购价格。第四，dealer balance sheet capacity，也就是交易商资产负债表容量，会限制中介能力。即使市场一边有现金、一边有证券，dealer 若受资本占用、季末报表或风险限额约束，资金也未必顺畅流动。

第一个例子看国债融资。假设某日大量新发国债交割，投资者需要临时融资来接券。若银行和 dealer 愿意扩表，repo 市场可以平稳吸收供给；若资产负债表容量紧，general collateral repo rate，也就是一般抵押品回购利率，可能突然上行。研究员看到这个现象，不能只说短端利率上升，还要问是国债供给冲击、现金准备金不足，还是中介资产负债表变贵。

第二个例子看相对价值交易。一个基金想做 cash futures basis trade，也就是买入现金国债、卖出国债期货来赚取基差收敛。它需要在 repo 市场融资持有的国债。如果 repo rate 上升，融资成本会吃掉基差收益；如果某只可交割券变成 special，融资成本可能反而降低，但可借券数量有限。模型里的 expected return 不能只看期货和现券价差，还要把 repo rate、haircut 和滚动融资风险放进去。

常见误区是把 repo 当成普通银行贷款。Repo 的核心风险不只是借款人信用，还包括抵押品价格波动、haircut 调整、期限错配和交易商中介能力。另一个误区是看到 repo rate 上行就直接判断央行要收紧。很多时候，短期尖峰来自税期、国债结算、季末报表或准备金分布不均，需要和 SOFR、T bill、OIS 以及央行回购工具一起读。

实用 takeaway 是，看到 repo 市场波动时，先拆三件事：谁缺现金，谁缺抵押品，谁缺资产负债表容量。再把答案落到资金成本、杠杆交易、国债相对价值和短端利率传导上。Repo 看起来是后台融资工具，但它常常决定前台交易能否持有到预期收敛。对面试和晨会来说，能把 repo 讲成现金、抵押品和中介容量的三方平衡，比只背定义更有判断力。
