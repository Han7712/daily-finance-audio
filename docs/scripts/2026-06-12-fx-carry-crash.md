# FX Carry Crash

上一次复习问题是：如果美元上涨，同时美股也上涨、信用利差没有明显走阔、美国实际收益率上行，你会把它放在 Dollar Smile 的哪一段？我会先放在右侧，也就是美国增长和回报优势推动美元走强。因为这组信号不像危机里的抢美元现金，信用利差没有明显恶化，股市也在涨，说明资金更可能在追美国资产回报。还要确认几件事：美债实际收益率是否相对其他市场上行，盈利预期是否支撑美股，cross currency basis 有没有变差，DXY 之外的广义美元是否同步走强。

今天的问题是：为什么一笔外汇 carry trade 明明每天都在赚利差，最后却可能在几天内把几个月的收益全部吐回去？FX Carry Crash 到底崩在哪里？

FX Carry Trade，中文可以理解为外汇利差交易。基本做法是借入低利率货币，比如日元或瑞郎，再买入高利率货币，比如澳元、墨西哥比索或某些新兴市场货币，赚取两边的利差。FX Carry Crash，中文可理解为外汇利差交易崩盘，指这类交易在风险偏好转差、波动率上升或融资条件收紧时，被集中平仓，高息货币快速下跌，低息融资货币反而大涨。它的核心问题在于，利差还在，汇率波动和杠杆去化却突然变成主角。这也是为什么 carry 的收益分布常常左尾很厚。

机制可以从三步看。第一步是平稳期的吸引力。只要市场相信高息货币不会大幅贬值，carry，也就是持有期间赚到的利差收入，就像一笔稳定票息。很多模型会把它放进预期收益。第二步是风险约束开始收紧。外汇波动率上升后，同样一笔头寸消耗更多风险预算，基金要降杠杆，银行也会提高保证金要求。第三步是平仓方向高度一致。做 carry 的人通常都在买高息货币、卖低息货币；出事时大家要反向交易，买回 funding currency，也就是融资货币，同时卖出 target currency，也就是投资货币。价格会因为同向拥挤而跳得很快。

第一个例子看澳元兑日元。平稳阶段，投资者借日元买澳元，赚取澳洲利率和日本利率之间的差。若全球股市突然下跌、商品价格走弱、外汇波动率上升，澳元会被当作风险货币卖出，日元会因为平仓买盘而升值。投资者原本以为一年可以赚几个百分点利差，但汇率两三天的变化就可能超过全年 carry。

第二个例子看墨西哥比索。比索利率较高时，许多投资者会把它当作高 carry 货币。假设美国实际利率上行，美元流动性收紧，新兴市场基金出现赎回。比索的高票息还在，但投资者更关心能不能退出、能不能控制回撤。若仓位太拥挤，卖盘会先压低现货汇率，随后触发更多止损，利差收入就很难保护本金。

常见误区是把高利率当作安全垫。高利率确实提供收入，但它经常是风险补偿，不是免费的午餐。另一个误区是只看即期汇率。外汇远期价格已经把利差部分反映进去，所以真正要判断的是 spot move，也就是现货汇率变动，会不会大到盖过 carry 收入。

实用 takeaway 是，做研究或建模时，不要只按名义利率给货币排序。你要同时看实际利率、经常账户、外储、仓位拥挤度、外汇波动率、融资货币方向，以及这笔交易和股票、信用利差的相关性。面试里被问到高息货币时，也要主动补一句：carry 好赚的时候通常很慢，亏损发生时可能很集中。

明天的复习问题是：如果一个高息货币过去三个月波动率很低、利差很高，但 VIX 上升、美元融资指标变紧、基金持仓也偏拥挤，你会继续加仓 carry trade，还是先降仓位？你会看哪些指标来确认？
