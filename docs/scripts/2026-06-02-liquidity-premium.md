# Liquidity Premium

上一次复习问题是：当 real yield 上升但 breakeven inflation 下降时，你会怎样判断这是增长预期改善、货币政策收紧，还是风险偏好变差？一个合格回答，要先把名义利率拆开。若实际收益率上升同时信用利差收窄、股票盈利预期改善，增长解释更有力；若短端实际利率抬升、风险资产承压，政策收紧更重要；若长端期限溢价和美元同步上行，风险偏好或国债供给压力可能在主导。

今天的问题是：为什么两只现金流和信用质量相近的资产，交易更困难的那一只，通常需要给投资者更高的预期回报？

Liquidity Premium，中文可叫流动性溢价，指投资者为了持有不容易快速、低成本、确定价格卖出的资产，要求的额外补偿。这里的流动性，不只看有没有人买，还要看成交速度、成交规模、价格折让和市场压力下的可靠性。最常见的观察变量包括 bid-ask spread，也就是买卖价差，market depth，也就是市场深度，以及 price impact，也就是大额交易对价格造成的冲击。

机制可以分四层看。第一，交易成本会直接降低回报。买入时付更高卖价，卖出时接受更低买价，价差越宽，投资者要求的补偿越高。第二，价格冲击会放大组合调仓成本。一个基金如果想卖出冷门债券，报价可能会随着订单规模下调，账面价格和真实可成交价格之间出现差距。第三，时间风险也有价值。如果资产需要几天、几周甚至几个月才能变现，投资者在这段时间失去重新配置资金的灵活性。第四，流动性有周期性。市场平静时看起来容易成交的资产，在赎回、保证金追缴或风险预算收缩时，可能突然缺少买方，所以流动性溢价常常在压力时期跳升。

第一个例子看信用债。两只投资级债券来自同一家公司，期限和条款相近，但一只是新发行的 benchmark bond，也就是机构常用来交易和报价的基准债，另一只是发行量小、成交稀少的老券。老券可能给出更高收益率。这个差额未必表示公司违约风险更高，也可能是在补偿投资者未来卖出时需要接受更宽价差和更低成交确定性。

第二个例子看私募资产。Private credit，也就是非公开市场直接贷款，可能比公开高收益债提供更高票息。部分补偿来自信用风险，部分来自流动性限制。投资人通常不能每天卖出头寸，估值也依赖模型和少量交易。若未来资金需求很确定，投资人可以承受这类锁定期；若组合需要随时应对赎回，表面上的高收益可能并不够补偿真实流动性风险。

常见误区是把流动性溢价和信用利差混在一起。信用利差主要补偿违约损失、评级迁移和周期风险；流动性溢价补偿的是以合理价格成交的难度。另一种误区是认为不流动资产一定更赚钱。溢价是要求回报，不是保证回报。如果买入价格已经过高，或者压力期被迫卖出，投资者可能既承担低流动性，又拿不到足够补偿。

实用 takeaway 是，读研报或建模型时，不要只比较收益率高低。要问四个问题：如果今天卖，能卖多少规模；需要付多大价差；压力期谁会接盘；估值是可成交价格还是 mark-to-market，也就是按市场价格重估。回答清楚这些问题，才能判断高收益是投资机会，还是流动性陷阱。
