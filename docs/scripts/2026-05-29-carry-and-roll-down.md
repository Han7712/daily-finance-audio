# Carry and Roll Down

上一次复习问题是：当 implied volatility 明显高于 realized volatility 时，你会检查哪些证据，来判断这是合理的尾部风险补偿，还是过度拥挤的卖波动率交易？一个实用回答，是看未来事件密度、期权供需、仓位拥挤、保证金压力，以及压力期损失是否会超过平时收取的期权费。今天我们从期权风险补偿转到固定收益组合的持有收益。

今天的问题是：债券投资者常说这只债有 carry，也有 roll-down。它们分别赚什么钱？为什么在利率和信用利差没有明显变化时，债券价格仍可能产生回报？

Carry and Roll Down，中文可以理解为持有收益与曲线下滑收益。Carry 指持有债券期间获得的票息、应计利息或利差收入，扣除融资成本后留下的收益。Roll-down 指时间过去后，债券剩余期限变短，在收益率曲线形状不变的假设下，债券会沿着曲线移动到较短期限对应的收益率，价格因此变化。若曲线向上倾斜，较短期限收益率通常更低，债券价格可能上升。在组合管理里，这两个概念常用于回答一个问题：如果今天买入并持有一段时间，且市场定价大体不变，组合自身能产生多少预期回报。

机制可以分四步看。第一，债券总回报先拆成收入和价格变化。收入部分来自 coupon，也就是票息，以及信用债的 spread carry，也就是利差带来的额外补偿。第二，价格对收益率变化很敏感。Duration，中文是久期，衡量收益率变动一单位时价格大致变动多少。第三，roll-down 来自时间本身。假设一只五年期债券持有一年后变成四年期债券，如果四年点收益率低于五年点，价格会因贴现率下降而受益。第四，carry 和 roll-down 都依赖假设。融资成本上升、曲线变平、信用利差走阔，都会吃掉原本看起来稳定的持有回报。

第一个例子看国债组合。假设五年期国债收益率为百分之四点二，四年期为百分之三点九，曲线向上倾斜。投资者买入五年期债券并持有一年，若整体曲线不变，债券会从五年点滚到四年点，收益率下降约三十个基点。若久期接近四年，粗略价格贡献约为百分之一点二，再加上一年票息收入，构成总回报。这个例子说明，在利率水平不变的情景下，期限结构也能影响收益。

第二个例子看投资级信用债。假设一只三年期公司债相对国债有一百二十个基点信用利差，票息看起来不错。若公司基本面稳定、利差曲线较陡，持有人可能同时赚 coupon、spread carry 和部分 roll-down。但如果行业需求转弱，市场把同类公司的利差从一百二十个基点重定价到一百八十个基点，久期带来的价格损失可能覆盖全年 carry。做信用研究时，不能只说票息高，还要问这份 carry 能承受多少 spread widening，也就是利差走阔。

常见误区是把 carry 当成确定收益。Carry 常常比较平滑，所以容易让人低估尾部风险。另一个误区是把 roll-down 当成免费的曲线收益。它成立需要曲线形状大致保持，若央行路径、供给压力或期限溢价改变，曲线可能整体上移或局部变陡，原先的 roll-down 会消失，甚至转成亏损。

实用 takeaway 是，读固定收益策略或做债券组合模型时，把预期回报拆成 carry、roll-down、利率变动、信用利差变动、融资成本和违约损失。然后给每一项配一个压力情景，例如收益率上行五十个基点，或信用利差走阔五十个基点。只要每一项都能解释清楚，就能判断收益来自可重复的持有补偿，还是来自对曲线和利差的隐含押注。
